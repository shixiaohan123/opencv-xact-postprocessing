# OpenCV Post-processing for XACT Bone Reconstruction
Self-directed mini project for medical image processing, based on the course Medical Signal and Image Processing.

## Overview
This demo performs conventional post-processing on simulated XACT reconstructed bone images.

## Processing pipeline
1. Gaussian filtering for noise reduction
2. Global histogram equalization
3. CLAHE adaptive local contrast enhancement
4. Canny edge detection for bone boundary extraction

## Tools
OpenCV (cv2), NumPy, Matplotlib
